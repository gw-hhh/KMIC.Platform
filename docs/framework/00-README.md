## 新框架约束

- 后端 .NET 10，前端 Vue 3。
- 部署：Linux + Docker。
- 数据库：PostgreSQL。
- 新框架独立设计，旧系统只作参考，不要求兼容旧表结构和接口；旧数据迁移、新旧过渡等问题后续单独处理。
- 技术选型已确认，见 03-tech-selection.md。

## 约定

- 标注：`待决` = 需要负责人拍板；`待确认` = 需要核实的事实；`假设` = 未验证的推断。
- 架构图使用 Mermaid。
- 已确认文档的修订直接改正文；只有决定变了才在文末“修订记录”登记一行，写法修正和实现时补的细节写在提交说明里（2026-11-19 起，原为每次修订都登记）。
- `设计候选` = 设计依赖尚未验证的数据库或平台行为，对应原型（08 第 4 节）验证通过前不作为实施依据（2026-11-05）。
