- 状态：结论已得出，成立；没有待决事项（2026-11-06）
- 来源：08 第 4 节原型 #10（非阻断）；06 D8 与“`待确认`：PG 克隆模板库时要求模板库没有活动连接”
- 原型代码：分支 `spike/06-07-10-ef-and-testing` 的 `spikes/06-07-10-ef-and-testing/`（与原型 #6、#7 共用；一次性代码，不合入主干）
- 环境：xUnit v3 4.0.2；Testcontainers 4.16.0；Npgsql 10.0.3；PostgreSQL 18

## 1. 结论

**成立，06 D8 的方案可以直接实现，`待确认` 关闭。**

| 要求 | 结论 |
|---|---|
| xUnit v3 程序集级夹具 | `[assembly: AssemblyFixture(typeof(TemplateDatabase))]`；整个测试程序集只创建一次（测试中断言实例数为 1） |
| 类级夹具使用程序集级夹具 | 类级夹具的构造函数直接注入程序集级夹具，可行 |
| 每个测试类一个克隆库，并行互不可见 | 两个测试类并行、时间上重叠，各自只看到自己写入的行 |
| 模板库上有活动连接时 | 克隆失败：`55006 source database "kmic_template" is being accessed by other users`。**连接关闭后回到连接池，物理连接仍连着模板库，同样算活动连接** |
| 怎样保证没有活动连接 | 迁移模板库的连接串设 `Pooling=false`（用完即断开）；或迁移后释放该数据源。之后克隆成功 |
| 并发克隆同一个模板库 | 8 个同时克隆全部成功，共 106 ms |
| 克隆耗时 | 默认策略 `WAL_LOG` 单次约 30 ms；`FILE_COPY` 首次较慢、之后相近，对小库没有优势，用默认值 |

6 项测试通过（其中克隆耗时 2 项只记录数值），连续运行 3 次结果相同。
