# S0-04 依赖版本与许可核实

- 状态：完成（2026-11-05）
- 方法：2026-11-05 直接查询官方一手数据：NuGet v3 接口（版本、`nuspec` 中的许可、发布日期）、npm 官方源（版本、许可、`peerDependencies`、`engines`）、各项目仓库的版本标签与 LICENSE 原文、.NET / Node.js / PostgreSQL 官方发布元数据。可信度均为“高”。
- 用途：S0-05 写 `global.json`、`Directory.Packages.props`、前端 `package.json` 时按本表锁定；关闭 03、06、F07、ADR-0032、R01 中“锁定版本时核实”的待确认项（第 6 节）。

## 1. 锁定规则

| 范围 | 方式 |
|---|---|
| .NET SDK | `global.json` 固定 10.0.403，`rollForward: latestPatch`（只接受 10.0.4xx 的补丁，开发机与 CI 的编译器一致） |
| 后端包 | 中央包管理 `Directory.Packages.props`，写精确版本；项目文件中不写版本 |
| 前端包 | `package.json` 写精确版本（不用 `^`、`~`），提交 `pnpm-lock.yaml`；`packageManager` 字段固定 pnpm 版本 |
| CI 工具 | 工作流中固定版本，并按 ADR-0032 的供应链加固规则校验下载物的校验和 |
| 升级 | 一律经合并请求：CI 全部通过后合入；大版本升级先在本表登记理由 |

## 5. 发现与处理

| # | 发现 | 处理 |
|---|---|---|
| 1 | TypeScript 的 latest 已是 7.0（原生编译器），但 typescript-eslint 8.72.1 只支持到 `<6.1.0` | 锁 6.0.3。与 F02 D3“TypeScript 7 待工具链支持后升级”一致 |
| 2 | Stylelint 18.0.0 于 2026-11-03 发布，而 SCSS 规则集、`stylelint-declaration-strict-value` 只支持到 17 | 锁 17.16.0 |
| 3 | Pinia 已有 4.x（4.1.0，2026-10-14，要求 Vue ≥ 3.5.11）；3.x 最后一版是 2025-11 的 3.0.4，已不再更新 | 锁 4.1.0。Pinia 在本系统只存会话、偏好等少量全局状态（F03），升级影响面小 |
| 4 | Antdv Next 依赖 VueUse `^14.4.0`；VueUse latest 是 15.0.0 | 锁 14.4.0，与组件库一致，避免打包两份 VueUse；组件库升级到 15 时一起升级 |
| 5 | vxe-table 在运行时导入 `@vxe-ui/core` 与 `xe-utils`，但 `package.json` 未声明依赖；`vxe-pc-ui` 只出现在类型声明文件中 | 三者都安装：前两者为运行时依赖，`vxe-pc-ui` 为开发依赖（只提供类型）；不注册 `vxe-pc-ui` 的界面组件，悬停提示与加载用组件库样式（F07）。**关闭 F07 的待确认项**：所用部分全部为 MIT |
| 6 | Gitea 在 1.27.3 之后版本号改为 28.x（最新 28.3.0）；act_runner 更名为 Gitea Runner（`gitea.com/gitea/runner`，5.4.0） | 升级目标为 28.3.0。跨大版本升级：先完整备份（数据库与数据目录），在测试实例上按官方发布说明演练后再升级生产；这些写入 S0-03a 操作说明。ADR-0032 加补充说明（名称与版本） |
