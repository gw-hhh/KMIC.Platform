# 实施：进度与待办

本目录记录实施阶段的任务、进度、操作说明，以及“到时候必须做”的待办。

## 1. 各类清单在哪里

| 清单 | 内容 | 位置 |
|---|---|---|
| 阶段任务 | 当前阶段要完成的任务与进度 | 本目录的各阶段文档（第 2 节） |
| **实施待办（本文第 3 节）** | 平台设置、账号、本机环境、费用、依赖版本跟进、实施中的验证：现在不做，满足触发条件时必须做 | 本文 |
| 设计延后事项 | 框架设计中延后到第一个业务需要时再做的能力 | `docs/framework/00-README.md`、`docs/frontend/00-README.md` 的“延后事项”表 |
| 上线前置条件 | 首期上线前必须全部满足的条件 | `docs/framework/08-roadmap.md` 第 5 节 |

规则：开始一个阶段、写新文档或做平台设置之前，先对照本文第 3 节；命中触发条件的待办在同一项工作中处理，完成后移到第 4 节并写明日期。新的待办随时登记，写明触发条件、负责方与来源。
