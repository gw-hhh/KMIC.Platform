## 1. 退出标准（08 第 2.2 节）

测试环境中可以：首个管理员经 `Operator` 初始化 → 登录 → 配置角色与数据范围 → 用 `Sample` 走完新建、提交、审批、附件、通知、审计查询全流程；访问上下文加载耗时达到 05-04 第 6.1 节目标（压测验证）。

其中“测试环境”依赖阿里云账号与部署（并行线 D、实施待办 T-08、T-20），本机能做的部分是：整套流程在 `Kmic.Api.Tests`（WebApplicationFactory + 真实 PG）里端到端通过。压测在本机 Docker PG 上先做一轮，数据作参考，不替代测试环境的结果。
