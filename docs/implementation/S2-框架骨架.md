## 3. 本阶段的工作方式

- 每个任务先读对应设计文档，按文档实现；实现中发现设计缺口、不一致或不可行，先修订文档并说明，再改代码（`CLAUDE.md`）。
- “完成”按 `CLAUDE.md` 的开发规则：代码在正确的项目；测试真实运行并通过；`dotnet run scripts/check.cs` 通过；未运行的测试写明原因。
- 代码中不写设计文档的节号与编号，也不用临时【引用】（T-17 已于 2026-11-11 关闭）；对照设计文档写在提交说明里。
