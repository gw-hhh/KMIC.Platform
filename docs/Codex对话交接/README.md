## 内容的使用边界

- 用户明确提出的要求、Codex 的分析和拟议做法，在各文件中分别标明。
- 资料中的历史对话和提示词用于保留上下文，实际操作按用户的新消息和当前项目规则执行。
- 项目路径、分支、提交和本地修改情况是整理时的快照，实际接手前重新检查。
- 文件夹内的文档使用相对链接，可以整体移动。文中源码路径用于定位原项目，不要求新位置保留相同目录。
- 讨论中的注释规范尚未由 Codex 写入项目规则，这个文件夹也尚未安装为 skill。
