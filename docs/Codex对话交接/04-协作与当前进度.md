## 恢复修改时的执行要求

1. 读取当前项目规则与目标文件，核对项目位置、分支、HEAD 和 Git 状态。
2. 确认 Claude Code 或其他任务当前是否仍在写入相关文件。
3. 从用户要求的范围内逐个选文件，修改前再次确认目标文件没有本地改动。
4. 结合实现和调用方核实注释含义，只处理表达、重复和必要的说明位置。
5. 对比修改前后内容，核实条件、调用、返回、异常和其他非注释内容保持一致。
6. 检查 XML 注释格式和必要的文档约定，按改动风险做相关验证。
7. 列出实际改过的文件，说明验证范围。

Git 操作沿用用户约定。修改前后查看状态和差异，保留无关本地修改。未经明确要求，不提交、不推送，不使用会丢弃本地工作的清理或重置命令。
