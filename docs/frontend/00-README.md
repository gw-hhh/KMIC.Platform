## 约束

- 后端契约以 `../framework/` 为准：接口约定（05-06）、认证与会话（05-04）、授权与 `allowedActions`（05-05）、时间显示（05-13 D4）、配置与字典（05-10）、文件与通知（05-11）、后台作业（05-08）。前端不另造契约；发现契约不合理时，回到后端文档修订。
- 前端类型由 OpenAPI 生成（03 第 4.5 节已定：openapi-typescript + openapi-fetch）。
- 前端与后端在同一仓库（`KMIC.Platform/web/`，08 D2），共用 CI（ADR-0032）。
- 参考资料（只作参考，不在其上改造）：用户已有的业务表格封装 vue-table（`C:/Users/cn02nbchugua04/Documents/程序/vue-table`，F02 第 5.1 节）；旧系统前端（`docs/legacy/`）；Vben Admin 5（设计参照）。

## 延后事项

后端延后事项表见 `../framework/00-README.md`；写前端文档或业务页面前两张表都要对照。

| 事项 | 触发条件 | 已定约束 | 来源 |
|---|---|---|---|
| 列表通用筛选协议（列头筛选、AND / OR 条件组） | 业务提出用户自定义组合条件、列头筛选的需求 | 作为强类型筛选的补充而不是替代；后端为每个列表声明允许的字段、类型、操作符，未知即整单拒绝；表达式树限深度与节点数、参数化、从已带数据范围的查询出发；区分 null / 空串 / 0 / false，相对日期按业务时区（R01 第 4 节）；前端由 `KTable` 提供，页面不自行拼表达式 | F03 D3 |
| 命名视图（保存常用查询） | 业务提出保存常用查询的需求 | 存为 `Ui.Table.*` 偏好族下的新键，不改现有列设置格式（F03 第 9.5 节）；保存的查询参数名即 OpenAPI 参数名，后端参数改名时须随版本兼容处理；视图不授予任何权限，数据范围照常由后端限定 | F03 D4 |
| 界面多语言 | 有不说中文的用户（海外机构或外籍员工、集团要求英文版、外部人员登录）；或业务提出多语言需求 | 按 F03 第 13.1 节：vue-i18n、`zh-CN` 为类型来源、模块内 `locales/`、`no-raw-text` 检查；后端文字与字典名由后端按 `Accept-Language` 返回（05-10 第 9 节）。为降低改造成本，现在起业务文字遵守 F04 规则：一句话完整写出不拼接、文字不埋在计算逻辑里、日期 / 数字 / 金额只经框架组件格式化。智能枚举显示名（2026-11-05 随 F05 D5 补充）：生成的 `enum-labels.ts` 作为 `zh-CN` 来源，键为 `枚举名.编码`，其他语言在模块 `locales/` 中按同一键补充 | F03 D10；F05 第 13 节 |
| 页面水印 | 业务或安全提出防截图外泄的要求 | 由外壳统一绘制；内容只含姓名、工号等非敏感标识；它是威慑手段而不是安全控制，不得以此替代权限与审计 | F06 第 12.2 节 |
| 锁屏 | 安全要求“离开座位须锁定” | 必须由服务端会话记录锁定状态（只在前端锁屏可被新开标签绕过）；解锁需验证密码；锁定期间令牌不可用于业务接口；需要回到后端 05-04 设计会话状态 | F06 第 12.2 节 |
| 合计行 | 第一个需要合计的列表 | 合计由后端按完整的筛选范围计算，列表响应增加可选的合计对象（需修订 05-06 第 6.1 节）；前端按列 ID 显示在表格底部合计行，不对当前页求和冒充总计 | F07 第 17.2 节 |
| 可编辑模式（明细行、行内编辑） | 第一个有明细行或行内编辑的业务模块，最迟在试点模块（阶段 4）之前；单独一份设计 | F05 第 9 节：数据是表单值中的数组，服务端错误路径回填单元格，新增行用临时键；与只读表格共用列定义与格式类型 | F07 第 17.2 节 |
| 多列组合排序 | 业务提出按多列组合排序 | 排序状态已是数组（F07 第 6.1 节）；后端最多 3 列（05-06 第 6.2 节）；界面为按住 `Shift` 点击表头追加，表头显示优先级数字 | F07 第 17.2 节 |
| 按条件批量（全选全部符合条件的记录） | 业务提出对整个查询结果做批量操作 | 不用按 ID 的批量命令：改为后台作业，以已提交的查询条件为参数，在后端重新按数据范围与条件取数（05-08、F05 第 12 节）；执行前显示将处理的数量并确认 | F07 第 17.2 节 |
| 单元格区域选择与复制 | 业务提出像电子表格一样框选复制 | 与行选择相互独立；复制显示文字；只作用于当前页已加载的数据 | F07 第 17.2 节 |
